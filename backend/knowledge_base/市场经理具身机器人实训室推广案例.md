# 市场经理具身机器人实训室推广案例

## 资料来源定位

本案例来源于市场推广场景访谈与团队整理的业务任务样例，已脱敏处理。现有企业官网及招聘渠道资料主要用于辅助判断具身智能、机器人、智能制造相关人才需求；关于职业教育政策、白名单赛事、专项资金和院校成功案例，后续需补充公开来源或标注“待核验”，系统生成时不得编造未经验证的数据。

本案例适合作为“市场经理使用大模型完成垂直行业推广任务”的训练样例，不直接作为政策、资金或院校案例的事实依据。

## 适用岗位

- 岗位方向：市场经理
- 具体场景：AI 教育公司面向高职院校推广具身机器人实训室
- 目标客户：高职院校实训中心主任、二级学院负责人、专业带头人、普通教师
- 训练能力：提示词改写、客户痛点拆解、产品价值翻译、事实核验、合规宣传

## 原始模糊任务

帮我写个给高职院校老师的推广方案，推销我们的具身机器人实训室。

## 原始任务问题分析

1. 对象不清楚：高职院校老师包含实训中心主任、系主任、专业教师等，不同角色的关注点不同。
2. 价值表达不足：只强调“推销”，没有说明客户为什么现在需要升级实训室。
3. 决策抓手不足：未说明政策背景、产教融合、设备更新、赛事成果、人才培养等可支撑预算申请的因素。
4. 产品价值没有翻译：如果只罗列机器人参数、算法名称和课程名称，客户难以判断对教学、就业和成果产出的实际价值。
5. 缺少事实核验要求：政策、赛事、资金、成功案例和数据必须有可靠来源，不能让大模型编造。

## 改进后的高质量任务

背景：我是某 AI 教育公司的市场经理，正在拓展广西、山东等地区的高职院校市场。我们的核心产品是“具身机器人实训室改造方案”，配套 K1 机器人和相关课程体系，可支持智能机器人、人工智能、智能制造等方向的实训教学和竞赛训练。

任务：请为我撰写一份《致实训中心主任：2026 秋季学期具身智能实训室升级建议书》的邮件或微信长文。

核心要求：

1. 政策与痛点前置：开头需要结合职业教育、产教融合、新质生产力人才培养、实训设备更新等背景，说明传统机械臂或单一设备实训可能难以覆盖新兴产业任务。若缺少具体政策来源，请标注“政策依据待补充”，不得编造文件名称。
2. 价值翻译：不要堆砌参数。应把技术能力翻译成学校可理解的教学价值，例如“支持学生接触更接近企业项目流程的实训任务，提升岗位适配能力和项目实践经验”；把维保服务翻译成“降低学校额外维护压力，缓解实训教师技术支持负担”。
3. 利益显性化：可提出需要进一步核验的专项资金、产教融合项目、设备更新项目、白名单赛事等方向，帮助老师理解“经费从哪里来、成果如何呈现”。没有公开来源时必须写“待核验”，不能编造具体资金名称、申报通过率或获奖案例。
4. 行动指令清晰：结尾提供“预约实地演示”“获取详细预算表”“安排教师试用课”等低门槛行动入口，语气专业、诚恳，像行业顾问而不是强推销售。
5. 输出格式适合手机端阅读：结构清晰，重点信息可加粗，包含标题、开场痛点、方案价值、实施路径、成果预期、待核验资料清单和行动入口。

## 合规与反幻觉约束

- 不得编造具体学校名称、获奖等级、预算申报通过率、政策文件编号或专项资金名称。
- 如需使用成功案例，应要求用户提供学校名称、赛事名称、获奖等级和公开来源。
- 如无可靠案例，应输出“案例待补充”或“建议补充同类院校案例”，不能生成虚假案例。
- 宣传表达应避免绝对化和夸大承诺，例如“保证获奖”“必然通过申报”“毕业即具备 3 年工作经验”等。
- 推荐使用稳健表述，例如“提升学生接近企业真实项目流程的实践能力和岗位适配能力”。

## 可提炼知识点

1. 面向 B 端教育客户的推广，不应只写产品功能，应先判断决策角色、现实痛点、政策背景、预算来源和成果呈现方式。
2. 市场经理使用大模型时，需要把模糊需求转化为结构化指令，至少包含背景、目标客户、产品信息、核心卖点、输出格式、事实来源和合规约束。
3. 技术参数需要翻译为客户价值，例如教学价值、就业价值、竞赛成果、维护成本降低、教师使用负担降低。
4. 对政策、资金、赛事、案例等高风险信息，应要求大模型标注来源或列入待核验清单。
5. 高质量推广内容应体现“客户痛点 - 产品价值 - 实施路径 - 成果证明 - 行动入口”的链路。

## 可生成训练资源

### 定制化提示词模板

请你扮演一名懂职业教育和 AI 教育产品推广的市场顾问，基于我提供的产品资料和目标院校信息，为高职院校实训中心主任撰写一份具身机器人实训室升级建议书。

背景信息：

- 产品名称：【填写产品或方案名称】
- 目标地区：【填写省份或城市】
- 目标客户角色：【实训中心主任/系主任/专业带头人/教师】
- 已有资料：【产品介绍、课程体系、设备参数、服务方案、案例资料】

请输出：

1. 面向目标客户的开场痛点分析；
2. 产品能力到教学价值的转化说明；
3. 可支撑预算申请或成果展示的方向清单；
4. 手机端可阅读的邮件或微信长文；
5. 需要补充或核验的政策、赛事、资金和案例资料清单；
6. 预约演示、获取预算表或安排试用课的行动入口。

要求：不得编造政策、资金、赛事、学校案例和数据；如资料不足，请明确标注“待补充”。

### 实操指南

1. 明确客户角色：先区分实训中心主任、院系负责人、专业教师等对象。
2. 提炼核心痛点：从设备更新、人才培养、竞赛成果、教师维护压力、预算申请等角度找切入点。
3. 翻译产品价值：把技术能力转化为教学成果、学生实践能力、教师使用便利和学校成果展示。
4. 补齐事实依据：政策、赛事、资金和案例必须有来源，没有来源时进入待核验清单。
5. 设计行动入口：给出预约演示、获取预算表、试用课程等下一步动作。
