# 工业互联网告警运维规范

适用场景：工业互联网平台告警分析、设备状态监测、边缘网关异常、运维处置方案生成。

核心分析维度：
- 告警信息：告警类型、触发阈值、触发时间、影响设备、重复次数。
- 设备状态：在线状态、采集频率、运行负载、网络连接、历史健康度。
- 数据链路：传感器、边缘网关、平台接口、数据延迟和丢包情况。
- 影响范围：单设备、单产线、车间级、跨系统影响。
- 运维处置：确认告警真实性、定位责任边界、制定优先级、记录处置闭环。

输出要求：
1. 先判断告警真实性和紧急程度。
2. 标注可能原因、影响范围、处置优先级和复核人员。
3. 区分平台数据异常、设备异常和网络链路异常。
4. 对关键结论标注数据来源或待验证状态。
5. 不得编造日志、设备编号、阈值或历史记录。
