# 智能制造设备异常分析规范

适用场景：产线设备报警、传感器异常、工艺参数波动、质检异常追溯。

核心分析维度：
- 报警信息：报警时间、报警代码、报警频次、持续时长、影响工位。
- 运行数据：温度、压力、振动、电流、转速、节拍、良品率等关键指标。
- 工艺参数：参数设定值、实际值、近期调整记录、批次差异。
- 设备状态：维护记录、备件更换、点检结果、历史故障模式。
- 安全边界：涉及人身安全、设备损坏、批量质量风险时必须人工复核。

输出要求：
1. 区分事实数据、推测原因和待验证假设。
2. 给出 3 到 5 个可能原因，并按风险等级排序。
3. 给出可执行排查步骤，不得跳过安全确认。
4. 数据不足时标注需要补充的传感器记录、工艺记录或维护记录。
5. 不得编造设备型号、报警代码或检测数据。
