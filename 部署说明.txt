智训工坊｜腾讯云 CloudBase 国内公网部署

一、上传位置
1. 登录腾讯云控制台，进入“云开发 CloudBase”。
2. 新建环境后进入“云托管”，创建服务 promptcraft-pro。
3. 新建版本，选择“上传代码包”，上传本压缩包。
4. Dockerfile 路径填写：Dockerfile
5. 监听端口填写：8080
6. 开启公网访问，并将流量设置为 100%。

二、环境变量
HOST=0.0.0.0
PORT=8080
API_BASE_URL=https://api.deepseek.com/v1
MODEL_NAME=deepseek-chat
API_KEY=你的 DeepSeek API Key

API_KEY 只能填写在腾讯云控制台的环境变量中，严禁写入代码、压缩包或比赛材料。
如暂时不填写 API_KEY，系统仍可使用本地规则兜底模式运行。

三、部署后检查
1. 打开腾讯云分配的公网域名，应直接显示智训工坊首页。
2. 访问“公网域名/health”，应返回 status=ok。
3. 使用手机流量和无痕浏览器各测试一次。
4. 比赛系统中的账号、密码填写“无需登录”。

四、重要说明
腾讯云默认域名适合比赛测试，但可能显示一次安全提示中间页。
如需长期稳定对外服务，应绑定已备案的自定义域名。
